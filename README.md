# 回頭車（示範版 PWA）

懂化工、食品、藥用原料的車。這是一個**功能示範**，用來展示內部運費工具與回程媒合流程，**不是正式對外營運的平台**。

示範網站：<https://elmercheng911-png.github.io/huitouche-demo/>

## 這個示範做什麼

- 貨主刊登貨物（起訖、日期區間、貨類、重量、包裝、防潮／SDS 等需求、原運費）
- 車行／司機登記回程空車（路線、日期、車型、載重、證照）
- 依路線、日期、載重與貨類相容性計分媒合
- 危險物品數量檢查：氣體 50 kg、液體 100 kg、固體 200 kg，超過就擋下（第一版不接）
- 只媒合有營業貨車（黃牌）的車輛
- 每趟記錄原運費、回頭車價與節省金額，並有節省儀表板
- 示範登入（貨主／車行／調度），以及把媒合結果用 LINE 分享
- 可安裝到手機主畫面（PWA），也可以當網站用

## 這個示範不做什麼

- 不處理真實公司出貨或客戶資料（所有示例皆為虛構）
- 不收款、不代收代付；正式金流應交給持照第三方
- 不宣稱已取得汽車貨運業執照，也沒有真實客戶推薦

## 示範帳號

密碼皆為 `demo`。

| 身分 | 帳號 |
| --- | --- |
| 貨主 | shipper@demo.huitouche.tw |
| 車行／司機 | carrier@demo.huitouche.tw |
| 調度 | ops@demo.huitouche.tw |

把這個網站加入手機主畫面後，可當 App 使用。資料存在該裝置的瀏覽器（localStorage），可在設定頁匯出 JSON。之後若要接雲端，可在 `js/store.js` 換成 Firebase 或 Supabase 適配器，不必改畫面邏輯。

## 本地預覽

```bash
python3 -m http.server 4173 --directory .
```

瀏覽器開啟 <http://127.0.0.1:4173/>。
